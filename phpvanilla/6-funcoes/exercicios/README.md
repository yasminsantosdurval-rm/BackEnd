##### Conceito de Função

- **O que é uma função?:**

É um conjunto de comandos que recebe informações, realiza uma tarefa e devolve o resultado.

-**Vantagens:**

1- Deixa o programa mais organizado
2- Evita ficar repetindo códigos

>**Resumo:** Funções ajudam a deixar os códigos mais organizados e mais fácil de reutilizar.


##### Princípio DRY

-**Por que repetir código causa problemas?**

Imagine que você tenha o mesmo código escrito em 5 lugares diferentes. Depois você percebe que esse código tem um erro e precisa corrigir.

Você teria que procurar e corrigir nos 5 lugares. Se esquecer de um deles, o programa pode ficar funcionando de maneiras diferentes.

-**Como a função ajuda?**

Você coloca aquele código dentro de uma função. Quando precisar daquela tarefa, simplesmente chama a função.

Assim, se precisar fazer uma alteração ou corrigir um erro, você muda apenas dentro da função, e a mudança vale para todos os lugares que usam ela.
